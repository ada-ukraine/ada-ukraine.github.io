# Ada User Journal 2024/2 (червень)

Стислий огляд журналу по Ada за червень 2024, що у вдкритому доступі журнал
з'являється с затримкою в рік. Нажашь у цьому випуску тілки одна стаття нає
пряме відношення до Ада. Зміст:

* Фреймворк для покращення переносності та забезпечення коректності ядер операційних систем
* Алгебраїчні ефекти та статичний аналіз для критичних до безпеки додатків у Fuzion
* Ітеративний метод конфігурації бенчмарків для кількісної оцінки багатоядерних інтерференцій
* Підвищення надійності в роботизованому додатку без втрати безпеки
* Реконфігурована та масштабована Honeynet для кіберфізичних систем
* Програмно-орієнтований фреймворк безпеки для Edge та мобільного IoT
* Підтримка Ada в компіляторі ROSE
* Відображення «завдання -> потік» у OpenMP з використанням нечіткого прийняття рішень
